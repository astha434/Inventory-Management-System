# StyleVista E-Commerce Website

StyleVista is a simple and enjoyable online clothing store built with HTML, CSS, and JavaScript. It features a modern design, interactive shopping cards, customer reviews, blog recommendations, and a contact form.

## Features

- Responsive navigation bar
- Main banner with brand highlights
- Trending clothes section with interactive cards
- Customer reviews
- Blog recommendations
- Contact form
- Product details and buy page
- Responsive design for desktop and mobile

## Project Structure

- `E-com.html` – Main HTML file
- `E-com.css` – Stylesheet
- `E-com.js` – JavaScript for interactivity
- Images (`.webp`, `.jpg`, `.png`) – Product, review, and banner images

## Getting Started

1. Clone or download the repository.
2. Place all files in the same directory.
3. Open `E-com.html` in your browser.

## Customization

- Add or replace images for products and reviews.
- Edit product details, prices, and offers in the HTML.
- Update styles in `E-com.css` as needed.

## Dependencies

- [Font Awesome](https://fontawesome.com/) for icons (via CDN)
- [Google Fonts](https://fonts.google.com/) for typography (via CDN)
